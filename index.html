// five steps. four are a system. one is me.

how a piece gets made.

  1. 01

    listen

    // communication

    Find the one sentence the work has to make true. Then build the story so each beat causes the next: but, therefore. Never and then.

  2. 02

    write the rules

    // design

    Grid, type scale, color, motion, voice. Written down, so the brand survives other people using it.

  3. 03

    encode

    // code + ai

    The rules become templates, Python and SVG pipelines, and custom AI skills. One master file generates every size and every variation.

  4. 04

    review

    // judgment

    Everything passes through someone who knows what wrong looks like. AI drafts fast. I decide what ships.

  5. 05

    break one rule

    // personality

    One deliberate exception, placed where it does the most work. It’s the part people remember, and the part I never automate.
